# Open Movie & Poster Database (OpenPosterDB / Redflix System)

Automated High-Resolution Movie & TV Shows Data Source with Posters, Ratings, and Multi-Server Streaming Links.

## 🌟 Features
- **High-Resolution Posters**: Direct TMDB HD (`w500`), Ultra-HD (`original`), and thumbnail (`w185`) links.
- **Multi-Server Streaming Embeds**: Compatible with VidBolt, VidLink, Videasy, VidFast, VidCore, and AutoEmbed.
- **Automated Sync**: GitHub Actions workflow automatically updates trending and new movies on schedule.
- **Free CDN Access**: Zero hosting cost, high-speed CDN delivery via jsDelivr.
- **Clean JSON Datasets**: Ready-to-use structured JSON files for Android/iOS apps, Web apps, Kodi, and Stremio addons.
